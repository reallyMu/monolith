## 0. 一句话

选一个磁盘目录，按文件夹镜像出浏览夹；文本就地登记，非文本先转入导入目录再登记。同一文件只有一条资产，可以同时挂在多个夹；从最后一个夹拿掉 = 取消登记（不回 Root）。

## 1. 资产与夹

| | |
|---|---|
| 身份 | 仍是一条 `asset_instance` + `absolute_path` UNIQUE |
| 夹 | 多对多。挂接表 `(asset_id, browse_term_id)` UNIQUE，**不是** JSON 数组列 |
| 树 | 每个挂接夹下列出同一 `asset_id` |
| 改正文 / 转换 / 版本 | 打在这一条上 |

迁移：现有 `browse_term_id` 各写一行挂接后 **删除该列**（无双写）。

## 2. 从夹拿掉 / 删除登记

| 动作 | 结果 |
|---|---|
| 在夹 A 拿掉（A 不是唯一挂接） | 只删挂接 `(asset, A)`。其它夹仍在。文件仍在磁盘。 |
| 拿掉后挂接为零 | **取消整条资产登记**（instance + versions）。不挂 Root。文件与 `conversion_log` 保留（L7）。 |
| 只挂在 Root 上、从 Root 拿掉 | 同上：零挂接 → 取消登记。 |

最后一次拿掉须确认：将从资产库取消登记，文件还在磁盘。

不把「无处可去」的资产塞进 Root（会污染真正登记在 Root 的条目）。

拖到夹：尚未挂该夹则 **增加挂接**（不卸旧夹）。从夹离开只用「拿掉」。

删夹：仍仅空夹（无子夹、无挂接）。

## 3. 目录导入

入口：选磁盘目录 + 勾选「包含子目录」（默认开）。

1. 在 Root 下确保与该目录同名的浏览夹（已有同名同级则复用，不新建重名夹）。
2. 含子目录：相对路径上每一级子文件夹都 `ensure` 为嵌套夹（空目录也建夹）。不含：只处理该目录这一层文件，不建子夹、不进子文件夹。
3. 每个文件：
   - `file-types.json` 文本 → **就地**登记（路径不改），挂到对应镜像夹。
   - 仅 `convert-types.json` → 按同源覆盖 / 异源改名转入 **导入目录（inbox）**，登记 MD，`source_path` = 源文件绝对路径，挂到镜像夹。批量转换 **不** 逐个弹保存框。
   - 两张表都没有（如图）→ 跳过。
   - `.git` / `node_modules` / 名以 `.` 开头的文件与目录 → 跳过（不建夹）。
4. 路径已登记：不再建第二条资产，只 **补挂** 镜像夹（原夹保留）。
5. 跑完给汇总：新建 / 补挂 / 跳过（已登记仅补挂计入补挂）/ 不可转 / 转换失败。失败不中止其余文件。

## 4. 单次「生成资产」

未指定夹 → 挂 Root（一个挂接）。路径已存在 → 不新建；若当前不在所选夹则补挂。

## 5. 非目标

- 同一路径多条 `asset_id`
- 把转换 MD 按源目录层级再铺一份到磁盘
- 导入时搬/删源文件
- 监视目录自动导入
