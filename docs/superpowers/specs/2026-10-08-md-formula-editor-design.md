# Monolith — MD 工具栏公式编辑器

> 状态：已批准（对话确认方案 1 + A/C；设计草案用户「批准」）  
> 日期：2026-10-08  
> 关联：[MD 预览：公式 + Mermaid](./2026-10-07-md-math-mermaid-preview-design.md)

## 决定

1. **形态**：工具栏「公式」按钮 → 模态/锚定面板（方案 1）。上方模板条，中间 LaTeX 文本框，下方 KaTeX 实时预览；行内 `$…$` / 块级 `$$…$$` 可切换。
2. **默认**：新建默认**块级**；编辑已有时沿用原类型，用户可改。
3. **入口 A（工具栏）**：若 Monaco 光标落在某段 `$…$` / `$$…$$` 内 → 载入该公式进入编辑，确认后**替换**原定界符范围；否则新建插入。
4. **入口 C（预览）**：双击 TipTap `mathBlock` / `mathInline` → 打开同一面板并带上 latex + 类型；写回仍只改 Monaco 源码。
5. **源码权威**：仍在 Monaco；不引入 MathLive；不做预览就地 contenteditable。
6. **模板**：小集合（分数、根号、上下标、积分、求和、极限、矩阵骨架、常用希腊字母、`\infty` / `\pm` / `\rightarrow` 等），点选插入到 LaTeX 光标处；不做完整公式库。

## 面板字段

| 控件 | 行为 |
|---|---|
| 行内 / 块级 | 切换定界符形态 |
| LaTeX | 多行；新建且有非公式选区时可预填选中文本 |
| KaTeX 预览 | `throwOnError: false`，错误可见不崩溃 |
| 插入 / 更新 | 空 LaTeX 禁用；Esc / 取消关闭 |

块级写入形态：独立行 `$$\n{latex}\n$$`。行内：光标处 `$…$`。

## 实现落点

- `FormulaEditorModal.vue`（Teleport 面板，风格对齐现有 chars/table 浮层）
- `utils/mdMathRange.ts`：探测最近包围的 `$`/`$$` 范围；替换/新建包裹（简单边界规则，不解析嵌套转义全貌）
- `MathNodes` NodeView：`dblclick` → `MarkdownWysiwyg` → `App` 开面板；用 `sourceSpans` / 节点映射定位源码范围
- i18n 中英标题与按钮

## 非目标

- MathLive / 可视化结构编辑
- Mermaid 编辑器
- 独立设置项或更换渲染引擎
- 完整 TeX 宏包 / 公式库

## 验收

1. 工具栏可插入块级与行内，右侧预览正确。
2. 光标在公式内再开面板 → 可改并替换，不残留双份定界符。
3. 预览双击公式 → 编辑后源码与预览一致。
4. 模板插入后预览即时更新。
5. 非法 LaTeX 不崩溃，预览显示错误态。
