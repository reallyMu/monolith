# Monolith — 导入身份：同源覆盖 / 异源改名

> 状态：已批准（方案 A）  
> 日期：2026-10-06  
> 前置：[`2026-10-06-import-dir-unify-design.md`](./2026-10-06-import-dir-unify-design.md)

## 决定

导入目录是扁平的。文件名不当身份。

| | |
|---|---|
| 认人 | 转换 = 源文件绝对路径；剪藏 = 页面 URL。须完全相同才算同源。 |
| 同源 | 写回**上次**那份 MD（覆盖）。文件已删则仍用该路径重建（若已被别的来源占用则改名）。 |
| 异源同名 | 自动 `{stem}-2.md`、`{stem}-3.md`… 不弹窗、不手改。 |
| 区分 | 导入资源浏览器「来源」列。不加备注字段。 |

转换保存对话框仍弹出；预填路径已按上表算好。用户在对话框里另选路径视为显式覆盖，不再二次改名。

剪藏无 Native Messaging：扩展用 `chrome.storage` 记 URL→inbox 相对路径，同源 `conflictAction: overwrite`；未登记过则落盘后记下实际文件名。Chrome 若仍 uniquify 出 `skill (1).md`，以实际文件名为准并写入映射。

列表不改列。资产登记仍不搬文件。
